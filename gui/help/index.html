Cppcheck GUI

Cppcheck is a static analysis tool for C and C++ code. It looks for bugs such as undefined behavior, memory leaks, buffer overruns, null pointer dereferences and uninitialized variables, and it points out code that is suspicious, slow or hard to maintain. Cppcheck tries hard to avoid false positives: when it reports something there is usually a reason to look at it.

The Cppcheck GUI is a graphical front end for Cppcheck. With the GUI you can:

  • create and edit project files that describe what code to analyze and how to analyze it,
  • import Visual Studio solutions and projects, compile databases (compile_commands.json) and Borland C++ Builder 6 projects,
  • run the analysis in several threads and watch the results come in,
  • browse the warnings, read the source code next to them and follow the path that leads to each bug,
  • filter, hide, suppress and tag warnings,
  • open the code in your favorite editor,
  • save results as XML, text or CSV and print them,
  • try out small pieces of code in the scratchpad,
  • write configuration files for your own libraries.

Projects or quick analysis?

There are two ways to use the GUI:

  • With a project file (recommended). A project file (*.cppcheck) stores where your code is, the include paths, the preprocessor defines, the libraries you use, suppressions, tags and much more. The analysis is more accurate when Cppcheck knows these things, and you only configure them once. See Getting started and Project files.
  • Without a project file. Use Analyze > Files... or Analyze > Directory... to analyze some code quickly. See Analyzing without a project.

More information

The Cppcheck manual describes the analysis itself in more detail, including the command line tool, the configuration file format and addons. You can find it at https://cppcheck.sourceforge.io/manual.pdf.

The Cppcheck home page is https://cppcheck.sourceforge.io/. There you can download new versions, read about the checks and report problems.
