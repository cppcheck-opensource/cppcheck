PCRE2 is a library that is used by the optional "rules" feature for the command
line version of cppcheck. It is readily available on Linux and macOS, but
must be obtained separately for Windows.

Build instructions
------------------

Windows
-------

Visual Studio

Download the PCRE2 source code from https://github.com/PCRE2Project/pcre2/releases
and CMake (https://cmake.org/download/). Then build a static library from a
Visual Studio developer command prompt:

  cmake -S . -B build -A x64 -DBUILD_SHARED_LIBS=OFF -DBUILD_STATIC_LIBS=ON -DPCRE2_SUPPORT_JIT=ON -DPCRE2_BUILD_PCRE2GREP=OFF -DPCRE2_BUILD_TESTS=OFF
  cmake --build build --config Release
  cmake --install build --config Release --prefix pcre2-dist

Copy pcre2-dist\include\pcre2.h and pcre2-dist\lib\pcre2-8-static.lib (renamed to
pcre2-8.lib) into the /externals directory and select the "Release-PCRE" or
"Debug-PCRE" configuration in cppcheck.sln.


Linux
-----

The normal Makefile should work.

Install PCRE2 on Debian/Ubuntu might be needed:
  sudo apt-get install libpcre2-dev


Mac OSX
-------

Install PCRE2:

homebrew
  brew install pcre2

or macports
  sudo port install pcre2

The Makefile uses pcre2-config to find the include and library paths.
